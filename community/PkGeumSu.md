# PkGeumSu ( SamSiqui )
Olá, pessoal! 👋

Meu nome é Samuel Siquineli, tenho 26 anos e atualmente estou estudando Programação e Desenvolvimento de Software pela DIO (Digital Innovation One).

Meu objetivo é transformar todo o conhecimento que estou adquirindo em prática e, principalmente, entrar de vez no mercado de tecnologia, com foco em desenvolvimento Front-end, área na qual pretendo me especializar e construir minha carreira.

Tenho dedicado grande parte do meu tempo aos estudos. Hoje, cerca de 90% do meu tempo útil é voltado para aprendizado, prática e evolução como desenvolvedor. O restante desse tempo é dedicado à minha esposa, que também faz parte dessa caminhada e me apoia durante esse processo. ❤️

Estou construindo minha base desde os fundamentos, estudando conceitos, colocando a mão no código e tentando transformar teoria em projetos reais. Quero ir muito além de simplesmente assistir às aulas: meu objetivo é entender como as coisas funcionam, escrever código, quebrar a cabeça com bugs, pesquisar soluções, refatorar e aprender com cada error que aparece no console. 😂

Atualmente, meu foco está principalmente no ecossistema Front-end, buscando evoluir em tecnologias como HTML, CSS, JavaScript e, posteriormente, aprofundar meus conhecimentos em frameworks e ferramentas utilizadas pelo mercado, como React, Git e GitHub, além de boas práticas de desenvolvimento, responsividade, consumo de APIs, componentização e organização de código.

Sei que começar uma carreira em tecnologia aos 26 anos pode parecer, para algumas pessoas, um pouco tarde. Mas, sinceramente, não vejo minha idade como um blocker. Vejo como mais um desafio no caminho.

Não estou buscando atalhos. Estou construindo minha base, fazendo commit após commit, aprendendo com meus bugs e tentando evoluir um pouco mais todos os dias. 🚀

Minha meta é simples: me tornar um desenvolvedor Front-end competente, conseguir minha primeira oportunidade na área e continuar evoluindo constantemente.

Sei que ainda tenho muito code para escrever, muitos conceitos para aprender e muitos bugs para debugar, mas estou disposto a passar por cada etapa desse processo.

Um dia, quero voltar a este mesmo commit e atualizar este .md com uma frase diferente:

"Consegui minha primeira oportunidade como desenvolvedor Front-end."

E quando esse dia chegar, vou olhar para tudo que estou fazendo hoje e saber que cada hora de estudo, cada projeto, cada erro e cada linha de código valeram a pena.

O objetivo está definido. Agora é continuar no grind, manter a consistência e não dar git push no desistir. 😅💻

Nos vemos no próximo commit! 🚀
