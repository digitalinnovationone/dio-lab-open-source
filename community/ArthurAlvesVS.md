**Tecnologias:**

`Python` `Flask` `SQLAlchemy` `SQLite` `HTML` `CSS` `JavaScript` `Chart.js`

### 🤖 SmartSupport AI

Uma API de análise de tickets de suporte utilizando inteligência artificial, desenvolvida para auxiliar na automação da triagem inicial de solicitações de clientes.

O projeto combina desenvolvimento backend, integração com inteligência artificial, processamento estruturado de dados, persistência e testes automatizados.

**Principais funcionalidades:**

* Análise de tickets de suporte
* Categorização automática
* Classificação de prioridade
* Resumo de solicitações
* Sugestões de resposta geradas por IA
* Respostas estruturadas por meio da API
* Persistência de dados com SQLite
* Testes automatizados

**Tecnologias:**

`Python` `FastAPI` `Gemini API` `SQLite` `Pytest` `REST API`
