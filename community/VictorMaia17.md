## 🚀 Projetos em destaque

### Sistema de Gerenciamento de Carcinicultura

[![Repositório](https://img.shields.io/badge/GitHub-Repositório-181717?style=flat&logo=github)](https://github.com/Melgibsa/Sistema-Gerenciamento-Carcinicultura)

Sistema desenvolvido para apoiar o gerenciamento de fazendas de carcinicultura, com funcionalidades relacionadas ao controle de viveiros e ciclos produtivos.

**Principais funcionalidades e conceitos trabalhados:**
- Cadastro e gerenciamento de viveiros.
- Controle de ciclos produtivos, povoamento, amostragens e despesca.
- Implementação de regras de negócio e validações.
- Persistência de dados com Spring Data JPA e PostgreSQL.
- Versionamento do banco de dados com Flyway.
- Organização em camadas, com separação entre controllers, casos de uso/orquestração e gateways.

**Tecnologias:** Java 17, Spring Boot, Spring Data JPA, PostgreSQL e Flyway.
